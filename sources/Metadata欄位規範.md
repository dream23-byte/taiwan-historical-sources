# Metadata 欄位規範

> 以 **Dublin Core** 為基礎，針對臺灣歷史權威史料特性調整。
> 狀態：v1.0 草案（2026-07-30）

---

## 一、核心欄位（必填）

| # | 欄位名稱 | Dublin Core 對應 | 說明 | 範例 |
|---|---------|-----------------|------|------|
| 1 | **題名** | dc:title | 史料名稱或文件標題 | 《臺灣總督府公文類纂》第 123 冊 |
| 2 | ** creator** | dc:creator | 作者／製作機關 | 臺灣總督府民政部 |
| 3 | **日期** | dc:date | 史料產生日期（西元） | 1905-03-15 |
| 4 | **類型** | dc:type | 史料類別（對應分類表） | 官方檔案文書 |
| 5 | **來源** | dc:source | 所屬典藏機關 | 國史館臺灣文獻館 |
| 6 | **識別碼** | dc:identifier | 在原典藏機構的編號 | 00000012001 |
| 7 | **來源網址** | dc:source (URI) | 數位化版本的直接連結 | https://onlinearchives.th.gov.tw/... |
| 8 | **語言** | dc:language | 史料原文語言 | ja（日文）、zh（中文） |

## 四、史料類型分類表

| 分類碼 | 名稱 | 說明 |
|-------|------|------|
| T01 | 官方檔案文書 | 政府機關公文、命令、報告、統計等 |
| T02 | 方志與輿圖 | 地方志、古地圖、測量圖、堡圖 |
| T03 | 報刊與雜誌 | 報紙、期刊、公報、會報 |
| T04 | 人物傳記與家族史料 | 日記、書信、族譜、履歷、碑傳 |
| T05 | 照片與影像 | 寫真帖、照片、影片、明信片 |
| T06 | 統計與調查資料 | 人口普查、產業統計、地籍資料 |
| T99 | 其他 | 不屬於以上分類者 |

## 六、資料格式建議

| 儲存格式 | 用途 |
|---------|------|
| **CSV** | 主要工作格式，通用性最高，可用 Excel 或 Google Sheets 編輯 |
| **JSON** | 程式處理用，適合 API 匯入或網站後端使用 |
| **Markdown 表格** | 人眼閱讀用，適合放入 Obsidian 或 GitHub |

建議以 **CSV** 為主要儲存格式，每批資料附一份 Markdown 說明。
